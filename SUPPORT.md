# Support

Use GitHub Discussions for installation help, architecture questions and usage
guidance. Use GitHub Issues for reproducible defects and compatibility gaps.

Before asking for help, run:

```bash
pam --version
pam doctor .
```

Include the operating system and architecture, PAM/PHP/Laravel/Octane versions,
the smallest reproduction, expected behavior, actual behavior and sanitized logs.
Remove tokens, credentials, cookies, private URLs and application data.

Security vulnerabilities must follow `SECURITY.md` and must not be disclosed in
Issues or Discussions. Community support is best-effort and does not constitute
an SLA.
