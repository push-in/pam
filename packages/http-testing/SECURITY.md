# Security policy for `pushinbr/pam-http-testing`

This package is developed in the [PAM monorepo](https://github.com/push-in/pam)
under `packages/http-testing` and published to its own repository by the PAM release.
Fixes land in the monorepo and ship in the next release of the package.

Do not report vulnerabilities in a public issue. Use GitHub private
vulnerability reporting on the
[PAM repository](https://github.com/push-in/pam/security/advisories/new) and
include the package name, affected version, a minimal reproduction, the impact
and any known mitigation. Do not include production credentials, personal data
or active third-party targets.

Supported versions, response times and the disclosure process are those of the
root [security policy](https://github.com/push-in/pam/blob/main/SECURITY.md):
acknowledgement within 72 hours, an assessment within 7 days and a fix for
critical and high severity issues within 30 days, followed by a GitHub Security
Advisory naming the fixed versions.
