# Security policy

Please do not disclose vulnerabilities in a public issue. Report them privately
through GitHub Security Advisories in `push-in/pam` with a minimal
reproduction, affected versions and expected impact.

PAM Octane 1.x supports the latest PAM 1.x patch together with PHP 8.4,
Laravel 12 or 13 and Laravel Octane 2.19 or newer while those lines receive
upstream security fixes. Keep all four components on security-supported patch
releases. Pre-release package versions receive fixes only on their latest tag.
